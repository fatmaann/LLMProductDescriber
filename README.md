# LLM Product Describer

---

## Сервис для генерации описаний товаров

Этот проект представляет собой сервис для быстрой генерации описаний товаров, предназначенный для использования на маркетплейсах. Пользователь может ввести название и характеристики товара или загрузить фотографию, на основе которой автоматически создается описание. Взаимодействие с серверной частью реализовано через FastAPI, а для генерации описаний используется API LLM-модели от Mistral с адаптированным под задачу промптом.

---

## Основные функции

- **Генерация описания по текстовым данным:**  
  Пользователь вводит название, размер, цвет и материал товара. Сервис возвращает сгенерированное описание с использованием LLM-модели.

- **Генерация описания по изображению:**  
  Пользователь загружает фотографию товара. Сервис анализирует изображение и создает описание на основе визуальных данных.

- **Интеграция с Mistral API:**  
  Используется API Mistral для обработки текстовых и визуальных данных. Промпты адаптированы под задачи генерации описаний товаров.


## Архитектура решения

Проект включает следующие компоненты:

1. **FastAPI (Backend):**  
   Обрабатывает запросы от пользователей. Включает два основных эндпоинта: для текстовых данных и для изображений.

2. **Mistral API (LLM-модель):**  
   Используется для генерации текстовых описаний на основе введенных данных или изображений.

3. **Роутеры:**  
   - `text_router`: Обрабатывает запросы с текстовыми данными.  
   - `img_router`: Обрабатывает запросы с изображениями.

4. **Конфигурация:**  
   Настройки API ключей, моделей и промптов хранятся в `config.py`.


## Основные этапы работы

**Запрос по текстовым данным:**
1. Пользователь вводит характеристики товара (название, размер, цвет, материал).
2. Данные передаются в Mistral API, где генерируется описание.
3. Результат возвращается пользователю.

**Запрос по изображению:**
1. Пользователь загружает изображение товара.
2. Изображение кодируется в base64 и передается в Mistral API.
3. На основе визуальных данных генерируется описание, которое возвращается пользователю.

**Запуск сервиса:**
1. Сервис запускается через `uvicorn` на порту 8069.
2. FastAPI обеспечивает обработку запросов и маршрутизацию.


## Технологии

- **Фреймворки:**  
  - FastAPI (для backend)  
  - Mistral API (для генерации текста)

- **Утилиты:**  
  - `uvicorn` (для запуска сервера)  
  - `poetry` (для управления зависимостями)

- **Форматы данных:**  
  - JSON (для текстовых запросов)  
  - Base64 (для кодирования изображений)
